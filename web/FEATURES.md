# 功能特性说明

## 🎯 核心功能

### 1. 总览页面 (Overview)
**路径**: 默认首页

**功能模块**:
- **服务指标卡片** (4个)
  - 客户端 API Keys 数量
  - 接入条目总数
  - 认证文件数量
  - 请求统计总数

- **配置摘要面板**
  - Host 地址
  - Port 端口
  - Debug 模式
  - Auth Dir 路径

- **Provider 密度面板**
  - 各 Provider 的配置数量
  - 彩色标签区分不同类型
  - 支持 6 种 Provider：API Keys、Gemini、Claude、Codex、OpenAI Compat、Vertex Compat

- **最近接入状态**
  - 显示最近 3 个认证文件
  - JSON 格式展示详细信息

### 2. 接入配置 (Providers)
**路径**: 点击侧边栏"接入配置"

**功能模块**:
- **客户端 API Keys 编辑器**
  - 多行文本编辑
  - 每行一个 Key
  - 一键保存到后端

- **接入计数面板**
  - 实时显示各 Provider 数量
  - 彩色卡片展示

- **Provider 快照**
  - JSON 格式查看所有配置
  - 便于调试和验证

### 3. 认证文件 (Auth Files)
**路径**: 点击侧边栏"认证文件"

**功能模块**:
- **认证文件巡检**
  - 网格布局展示所有认证文件
  - 每个文件独立卡片
  - JSON 格式显示详细信息
  - 支持滚动查看大量文件

### 4. Raw YAML 编辑
**路径**: 点击侧边栏"Raw YAML"

**功能模块**:
- **配置文件编辑器**
  - 直接编辑 config.yaml
  - 等宽字体显示
  - 支持多行编辑
  - 一键保存并同步

## 🎨 设计特性

### 视觉设计
- **深色主题** - 护眼舒适，适合长时间使用
- **渐变背景** - 蓝紫色调，现代感十足
- **玻璃态卡片** - 半透明背景，模糊效果
- **渐变文字** - 标题使用渐变色，视觉焦点

### 交互设计
- **悬停效果** - 卡片、按钮悬停时有视觉反馈
- **点击反馈** - 按钮按下时有动画效果
- **焦点状态** - 输入框聚焦时有高亮边框
- **加载动画** - 数据加载时显示脉冲动画

### 响应式设计
- **桌面端** (>1200px)
  - 左侧边栏 + 右侧内容区
  - 指标卡片 4 列布局
  - 面板 3 列布局

- **平板端** (720px-1200px)
  - 上下布局
  - 指标卡片 2 列布局
  - 面板 2 列布局

- **手机端** (<720px)
  - 单列布局
  - 所有卡片堆叠显示
  - 优化触摸操作

## 🔐 安全特性

### 认证机制
- **管理密钥保护** - 所有 API 请求需要密钥
- **本地存储** - 密钥保存在浏览器 localStorage
- **Bearer Token** - 标准的 Authorization Header

### 数据安全
- **密码输入框** - 管理密钥输入时隐藏
- **HTTPS 支持** - 支持 TLS 加密传输
- **CORS 配置** - 后端配置跨域访问控制

## 📊 数据展示

### 实时同步
- **自动加载** - 输入密钥后自动加载数据
- **手动刷新** - 点击刷新按钮重新加载
- **最后同步时间** - 显示数据更新时间

### 数据格式
- **JSON 展示** - 结构化数据使用 JSON 格式
- **YAML 编辑** - 配置文件使用 YAML 格式
- **文本编辑** - API Keys 使用纯文本格式

## 🚀 性能优化

### 加载优化
- **并行请求** - 多个 API 同时请求
- **按需加载** - 切换页面时才加载对应数据
- **缓存机制** - 避免重复请求

### 渲染优化
- **虚拟滚动** - 大量数据时优化渲染
- **防抖节流** - 输入框优化
- **懒加载** - 图片和资源按需加载
